# thunar-stl-thumbnails

Generate thumbnails for STLs with Tumbler. Requires OpenSCAD to be installed.

![thunar](https://user-images.githubusercontent.com/35242550/182044826-e9520fed-98f5-47e9-8000-ea5c9ea56e3e.png)

## Installation

1. `sudo mv ./stl.thumbnailer /usr/share/thumbnailers/stl.thumbnailer`
2. `chmod +x ./stl-thumbnailer.sh`
3. `sudo mv ./stl-thumbnailer.sh /usr/bin/stl-thumbnailer.sh`

See: [https://docs.xfce.org/xfce/tumbler/available_plugins#customized_thumbnailer_for_stl_content](https://docs.xfce.org/xfce/tumbler/available_plugins#customized_thumbnailer_for_stl_content)
